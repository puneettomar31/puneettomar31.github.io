# Puneet Tomar — Portfolio

Static, responsive developer portfolio built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — portfolio, skills, selected projects, experience, education, and contact details.
- `resume.html` — printable resume summary.
- `assets/Puneet(2026)_Tomar_Resume.pdf` — current resume PDF linked from the portfolio.
- `project-edtech.html` and `project-filament-admin.html` — selected project overviews.
- `blog1.html` through `blog4.html` — development articles.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static web server. No build step or package installation is required.

The GitHub Actions workflow in `.github/workflows/deploy.yml` checks the site files and deploys the repository to GitHub Pages when changes are pushed to `main`.
